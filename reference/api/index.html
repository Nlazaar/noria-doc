    API REST v1

    Noria expose une API REST JSON disponible dès que le dashboard de monitoring est démarré (noria monitor ou noria run --monitor).

    Base URL : http://127.0.0.1:7070/api/v1

    Toutes les réponses sont en JSON. Les erreurs retournent un objet {"detail": "message"} avec le code HTTP approprié.

    Santé

    GET /api/v1/health

    Vérifie que le serveur est opérationnel.

    curl http://127.0.0.1:7070/api/v1/health

    {"status": "ok"}

    Runs

    GET /api/v1/runs

    Liste les 50 derniers runs du pipeline.

    curl http://127.0.0.1:7070/api/v1/runs

    [
  {
    "run_id": "abc123",
    "status": "finished_ok",
    "started_at": "2026-09-25T08:30:00",
    "finished_at": "2026-09-25T08:30:04",
    "duration_s": 4.2,
    "jobs_ok": 5,
    "jobs_ko": 0,
    "rows_written": 12450
  },
  ...
]

    GET /api/v1/runs/{run_id}

    Détail d'un run spécifique avec le résultat de chaque job.

    curl http://127.0.0.1:7070/api/v1/runs/abc123

    {
  "run_id": "abc123",
  "status": "finished_ok",
  "started_at": "2026-09-25T08:30:00",
  "duration_s": 4.2,
  "jobs": [
    {
      "name": "load_raw",
      "status": "ok",
      "duration_s": 1.1,
      "rows_written": 5000,
      "error": null
    },
    {
      "name": "anonymize_for_analytics",
      "status": "ok",
      "duration_s": 0.8,
      "rows_written": 5000,
      "error": null
    }
  ]
}

    Jobs

    GET /api/v1/jobs

    Liste tous les jobs du pipeline avec leur configuration et dernier statut connu.

    curl http://127.0.0.1:7070/api/v1/jobs

    [
  {
    "name": "load_raw",
    "type": "sql",
    "target": "raw.customers_raw",
    "write_mode": "replace",
    "tags": ["daily"],
    "last_status": "ok",
    "last_run_at": "2026-09-25T08:30:01"
  },
  ...
]

    Lignage

    GET /api/v1/lineage

    Lignage du pipeline — sources et cibles de chaque job.

    curl http://127.0.0.1:7070/api/v1/lineage

    {
  "pipeline": "mon_pipeline",
  "entries": [
    {"job": "load_raw",    "table": "raw.customers_raw",    "role": "target"},
    {"job": "build_kpis",  "table": "analytics.customers",  "role": "source"},
    {"job": "build_kpis",  "table": "reporting.daily_kpis", "role": "target"}
  ]
}

    Analyse d'impact

    GET /api/v1/impact/pipeline/{nom}

    Sources et cibles d'un pipeline donné.

    curl http://127.0.0.1:7070/api/v1/impact/pipeline/mon_pipeline

    {
  "pipeline": "mon_pipeline",
  "sources": [
    {"table": "raw.customers_raw", "job": "anonymize_for_analytics"}
  ],
  "targets": [
    {"table": "analytics.customers", "job": "anonymize_for_analytics"},
    {"table": "reporting.daily_kpis", "job": "build_kpis"}
  ]
}

    GET /api/v1/impact/table/{table}

    Pipelines qui lisent ou écrivent une table donnée.

    Le paramètre {table} accepte un point : raw.customers_raw → /api/v1/impact/table/raw.customers_raw.

    curl http://127.0.0.1:7070/api/v1/impact/table/analytics.customers

    {
  "table": "analytics.customers",
  "written_by": [
    {"pipeline": "mon_pipeline", "job": "anonymize_for_analytics"}
  ],
  "read_by": [
    {"pipeline": "reporting_pipeline", "job": "build_monthly_report"}
  ]
}

    GET /api/v1/impact/search?q={motif}

    Recherche de tables par nom (correspondance partielle).

    curl "http://127.0.0.1:7070/api/v1/impact/search?q=customers"

    ["raw.customers_raw", "analytics.customers"]

    GET /api/v1/impact/tables

    Catalogue complet de toutes les tables enregistrées.

    curl http://127.0.0.1:7070/api/v1/impact/tables

    [
  {"table": "raw.customers_raw",    "pipelines": ["mon_pipeline"]},
  {"table": "analytics.customers",  "pipelines": ["mon_pipeline", "reporting_pipeline"]},
  {"table": "reporting.daily_kpis", "pipelines": ["mon_pipeline"]}
]

    Déclencher un run

    POST /api/v1/trigger

    Lance un run du pipeline en arrière-plan et retourne immédiatement un token de suivi.

    curl -X POST http://127.0.0.1:7070/api/v1/trigger

    {
  "status": "accepted",
  "token": "f7a2c8e1",
  "message": "Pipeline lancé en arrière-plan"
}

    Le run est exécuté dans un thread daemon — surveiller son avancement via GET /api/v1/runs ou le dashboard web.

    Usage

    L'endpoint /api/v1/trigger est conçu pour les intégrations internes (webhooks, scripts d'automatisation). Il n'y a pas d'authentification — ne pas exposer le dashboard sur Internet sans proxy sécurisé.

    Codes HTTP

    Code Signification
    200 Succès
    202 Accepté (run lancé en arrière-plan)
    404 Ressource introuvable (run_id inconnu, table absente du catalogue)
    500 Erreur interne du serveur

    Exemples d'intégration

    Script de supervision

    #!/bin/bash
# Lancer le pipeline et attendre la fin
TOKEN=$(curl -s -X POST http://127.0.0.1:7070/api/v1/trigger | jq -r '.token')
echo "Run lancé, token: $TOKEN"

# Vérifier le dernier run
sleep 5
curl -s http://127.0.0.1:7070/api/v1/runs | jq '.[0] | {status, duration_s, rows_written}'

    Alerte si anomalie de volume

    # Vérifier le dernier run
STATUS=$(curl -s http://127.0.0.1:7070/api/v1/runs | jq -r '.[0].status')
if [ "$STATUS" = "finished_ko" ]; then
  echo "Pipeline en erreur — vérifier le dashboard"
fi

    Inventaire des tables (audit)

    # Exporter toutes les tables connues
curl -s http://127.0.0.1:7070/api/v1/impact/tables \
  | jq '.[] | .table' \
  | sort > inventaire_tables.txt
