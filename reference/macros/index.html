    Macros SQL cross-DB

    Les macros Noria sont des fonctions Jinja2 qui génèrent du SQL adapté au dialecte cible. Écrire {{ cast('col', 'VARCHAR') }} produit CAST(col AS VARCHAR) en DuckDB et col::VARCHAR en PostgreSQL — sans changer le code SQL.

    Macros built-in

    cast(col, type) — conversion de type

    {{ cast('montant', 'DECIMAL(18,2)') }}
{{ cast('id', 'VARCHAR') }}
{{ cast('date_str', 'DATE') }}
    Dialecte Résultat
    DuckDB CAST(montant AS DECIMAL(18,2))
    PostgreSQL montant::DECIMAL(18,2)
    BigQuery CAST(montant AS DECIMAL)

    date_trunc(period, col) — tronquer une date

    {{ date_trunc('month', 'date_commande') }}   -- premier jour du mois
{{ date_trunc('year',  'date_commande') }}   -- premier jour de l'année
{{ date_trunc('week',  'date_commande') }}   -- premier jour de la semaine
{{ date_trunc('day',   'ts') }}              -- minuit
{{ date_trunc('hour',  'ts') }}

    Périodes disponibles : second, minute, hour, day, week, month, quarter, year.

    Dialecte Résultat
    DuckDB DATE_TRUNC('month', date_commande)
    PostgreSQL DATE_TRUNC('month', date_commande)
    BigQuery DATE_TRUNC(date_commande, MONTH)

    current_timestamp() — timestamp courant

    {{ current_timestamp() }}    AS updated_at
    Dialecte Résultat
    DuckDB CURRENT_TIMESTAMP
    PostgreSQL NOW()
    BigQuery CURRENT_TIMESTAMP()

    concat(*args) — concaténation

    {{ concat('prenom', "' '", 'nom') }}
{{ concat('code_pays', "'-'", 'code_region') }}
    Dialecte Résultat
    DuckDB CONCAT(prenom, ' ', nom)
    PostgreSQL CONCAT(prenom, ' ', nom)
    BigQuery CONCAT(prenom, ' ', nom)

    coalesce(*args) — première valeur non NULL

    {{ coalesce('email_pro', 'email_perso', "'inconnu'") }}

    Tous les dialectes : COALESCE(email_pro, email_perso, 'inconnu')

    if_null(col, default) — valeur par défaut si NULL

    {{ if_null('commentaire', "'aucun'") }}
{{ if_null('montant', '0') }}

    Tous les dialectes : COALESCE(commentaire, 'aucun')

    safe_divide(numerator, denominator) — division sans risque de division par zéro

    {{ safe_divide('ca_total', 'nb_commandes') }}             AS panier_moyen
ROUND({{ safe_divide('nb_livres', 'nb_total') }} * 100, 1) AS taux_livraison

    Tous les dialectes : CASE WHEN nb_commandes = 0 THEN NULL ELSE ca_total / nb_commandes END

    to_char(col, format) — formater une date en texte

    {{ to_char(date_trunc('month', 'date_op'), 'YYYY-MM') }}   AS mois_label
{{ to_char('date_naissance', 'DD/MM/YYYY') }}              AS date_fr
    Dialecte Résultat
    DuckDB STRFTIME(col, 'YYYY-MM')
    PostgreSQL TO_CHAR(col, 'YYYY-MM')
    BigQuery FORMAT_TIMESTAMP('YYYY-MM', col)

    limit(n) — limiter le nombre de lignes

    SELECT * FROM ma_table
{{ limit(100) }}

    Tous les dialectes : LIMIT 100

    schema_table(schema, table) — référence qualifiée

    SELECT * FROM {{ schema_table(params.schema, 'clients') }}

    Résultat : main.clients (ou juste clients si schema est None)

    Combiner les macros

    Les macros se combinent naturellement :

    SELECT
    id_client,
    {{ cast('id_client', 'VARCHAR') }}                       AS id_str,
    {{ to_char(date_trunc('month', 'date_inscription'), 'YYYY-MM') }} AS mois_inscription,
    {{ coalesce('email_pro', 'email_perso', "'inconnu'") }}  AS email,
    ROUND({{ safe_divide('ca_total', 'nb_commandes') }}, 2) AS panier_moyen,
    {{ current_timestamp() }}                                AS updated_at
FROM {{ params.schema }}.clients
WHERE date_inscription >= {{ date_trunc('year', 'CURRENT_DATE') }}

    Macros utilitaires SQL

    Ces macros génèrent des fonctions de fenêtrage SQL standard (ANSI SQL). Elles sont disponibles dans tout template SQL Noria sans import — compatibles DuckDB, PostgreSQL et BigQuery.

    Origine : inspirées des fonctions SAS les plus fréquentes (PROC SORT NODUPKEY, RETAIN, LAG, PROC RANK). Voir aussi la page migration SAS.

    nodupkey(source, by, order_by='1') — dédoublonnage

    Équivalent SAS de PROC SORT NODUPKEY. Garde la première occurrence de chaque groupe de clés.

    -- Garder le dernier achat par client
SELECT *
FROM {{ nodupkey(source('commandes'), by='id_client', order_by='date_commande DESC') }}

-- Dédoublonner sur une clé composite
SELECT *
FROM {{ nodupkey('main.produits', by='categorie, fournisseur') }}

    nodupkey retourne une sous-requête prête à être utilisée dans un FROM. La valeur order_by détermine quelle occurrence est conservée (par défaut : la première dans l'ordre naturel).

    Paramètre Description
    source Nom de table ou source('id')
    by Colonnes de déduplication (séparées par ,)
    order_by Ordre pour choisir la ligne conservée (défaut : 1)

    running_total(col, by='', order_by='1') — cumul progressif

    Équivalent SAS de RETAIN cumul 0; cumul + valeur;

    SELECT
    mois,
    region,
    ca_total,
    {{ running_total('ca_total', by='region', order_by='mois') }}  AS ca_cumul_region,
    {{ running_total('ca_total', order_by='mois') }}               AS ca_cumul_global
FROM stats_mensuelles

    SQL généré : SUM(ca_total) OVER (PARTITION BY region ORDER BY mois)

    pct_of_total(col, by='') — part en pourcentage

    SELECT
    region,
    ca_total,
    {{ pct_of_total('ca_total', by='annee') }}     AS pct_ca_annee,
    {{ pct_of_total('ca_total') }}                 AS pct_ca_global
FROM stats_mensuelles

    SQL généré : ROUND(100.0 * ca_total / NULLIF(SUM(ca_total) OVER (PARTITION BY annee), 0), 2)

    lag_col(col, offset=1, by='', order_by='1') — valeur précédente

    Équivalent SAS de LAG(col) / LAG2(col).

    SELECT
    mois,
    ca_total,
    {{ lag_col('ca_total', order_by='mois') }}          AS ca_mois_precedent,
    {{ lag_col('ca_total', offset=3, order_by='mois') }} AS ca_trimestre_avant,
    {{ lag_col('ca_total', by='region', order_by='mois') }} AS ca_prec_region
FROM stats_mensuelles

    lead_col(col, offset=1, by='', order_by='1') — valeur suivante

    SELECT
    mois,
    ca_total,
    {{ lead_col('ca_total', order_by='mois') }}   AS ca_mois_suivant
FROM stats_mensuelles

    rank_by(by='', order_by='1', method='row_number') — rang

    Équivalent SAS de PROC RANK.

    SELECT
    id_client,
    ca_total,
    {{ rank_by(order_by='ca_total DESC') }}                       AS rang_global,
    {{ rank_by(by='region', order_by='ca_total DESC') }}          AS rang_region,
    {{ rank_by(order_by='ca_total DESC', method='dense_rank') }}  AS rang_dense
FROM stats_client
    method Comportement
    row_number Rang unique, pas d'ex-æquo (défaut)
    rank Ex-æquo possibles, sauts dans la numérotation
    dense_rank Ex-æquo possibles, pas de saut

    first_value(col, by, order_by) — première valeur du groupe

    Équivalent SAS de FIRST.variable (accès à la première valeur dans un groupe BY).

    SELECT
    id_client,
    date_commande,
    {{ first_value('date_commande', by='id_client', order_by='date_commande') }} AS premiere_commande
FROM commandes

    last_value(col, by, order_by) — dernière valeur du groupe

    Équivalent SAS de LAST.variable.

    SELECT
    id_client,
    {{ last_value('date_commande', by='id_client', order_by='date_commande') }}  AS derniere_commande
FROM commandes

    is_dup(by, order_by='1') — détection de doublon

    Retourne TRUE pour toutes les occurrences sauf la première — l'inverse de nodupkey.

    -- Marquer les doublons sans les supprimer
SELECT
    *,
    {{ is_dup(by='id_client') }} AS est_doublon
FROM commandes

-- Supprimer les doublons manuellement
SELECT * FROM (
    SELECT *, {{ is_dup(by='id_client', order_by='date_commande') }} AS _dup FROM commandes
) WHERE NOT _dup

    Combiner les macros utilitaires

    -- Rapport : top 3 clients par région, avec cumul et part de marché
SELECT
    region,
    id_client,
    ca_total,
    {{ running_total('ca_total', by='region', order_by='ca_total DESC') }}  AS ca_cumul,
    {{ pct_of_total('ca_total', by='region') }}                             AS pct_region,
    {{ rank_by(by='region', order_by='ca_total DESC') }}                    AS rang
FROM (
    SELECT * FROM {{ nodupkey(source('commandes'), by='id_client, region') }}
) t
WHERE {{ rank_by(by='region', order_by='ca_total DESC') }} <= 3
ORDER BY region, rang

    Macros utilisateur

    Crée des macros métier réutilisables dans sql/macros/ (fichiers .sql ou .sql.j2). Elles sont auto-chargées — aucun import nécessaire.

    -- sql/macros/metier.sql.j2

{# Catégorise un montant de commande #}
{% macro categorie_panier(col) %}
CASE
  WHEN {{ col }} < 50  THEN 'Petit'
  WHEN {{ col }} < 200 THEN 'Moyen'
  ELSE                      'Gros'
END
{% endmacro %}

{# Taux en pourcentage avec arrondi #}
{% macro taux_pct(num, denom, decimals=1) %}
ROUND({{ safe_divide(num, denom) }} * 100, {{ decimals }})
{% endmacro %}

    Utilisation dans n'importe quel SQL du projet :

    SELECT
    id_commande,
    montant,
    {{ categorie_panier('montant') }}                      AS categorie,
    {{ taux_pct('nb_livres', 'nb_commandes') }}           AS taux_livraison
FROM {{ params.schema }}.commandes

    Surcharger une macro built-in

    Si tu définis une macro utilisateur avec le même nom qu'une macro built-in, ta version a la priorité :

    -- sql/macros/override.sql
{% macro current_timestamp() %}GETDATE(){% endmacro %}
-- Maintenant {{ current_timestamp() }} → GETDATE() partout dans ce projet

    Appeler des macros built-in depuis une macro utilisateur

    {% macro mois_label(date_col) %}
{{ to_char(date_trunc('month', date_col), 'YYYY-MM') }}
{% endmacro %}
