    Foreach — Répétition de jobs

    Le foreach permet d'exécuter un même job plusieurs fois avec des paramètres différents — sur une liste statique ou sur le résultat d'une requête SQL. C'est l'équivalent du %DO %TO en SAS ou des boucles for en R.

    Boucle statique — foreach:

    Le job s'exécute une fois par entrée de la liste. Chaque entrée est un dictionnaire de paramètres injectés dans le SQL.

    jobs:
  rapport_region:
    sql: sql/rapport_region.sql
    target: "{{ params.schema }}.rapport_{{ region }}"
    write_mode: replace
    foreach:
      - { region: nord,  code: "59" }
      - { region: sud,   code: "13" }
      - { region: ouest, code: "44" }

    -- sql/rapport_region.sql
SELECT
    '{{ region }}'                AS region,
    COUNT(*)                      AS nb_clients
FROM clients
WHERE departement = '{{ code }}'

    Résultat : 3 tables créées — rapport_nord, rapport_sud, rapport_ouest.

    Boucle dynamique — foreach_query:

    La liste d'itérations est générée par une requête SQL. Chaque ligne de résultat devient un jeu de paramètres pour une itération.

    jobs:
  rapport_par_region:
    sql: sql/rapport_region.sql
    target: "{{ params.schema }}.rapport_{{ code_region }}"
    write_mode: replace
    foreach_query: >
      SELECT code_region, libelle
      FROM ref_regions
      WHERE actif = TRUE

    La requête retourne par exemple :

    code_region libelle
    IDF Île-de-France
    ARA Auvergne-Rhône-Alpes

    Chaque ligne devient une itération avec {{ code_region }} et {{ libelle }} disponibles dans le SQL.

    Contexte Jinja2 dans la boucle

    Dans chaque itération, un contexte loop est disponible en plus des paramètres de l'itération :

    Variable Type Description
    {{ loop.index }} int Numéro d'itération (commence à 1)
    {{ loop.index0 }} int Numéro d'itération (commence à 0)
    {{ loop.first }} bool true si c'est la première itération
    {{ loop.last }} bool true si c'est la dernière itération
    {{ loop.length }} int Nombre total d'itérations 
    {% if loop.first %}-- Première région{% endif %}
SELECT '{{ region }}' AS region, {{ loop.index }} AS num_iteration

    Options avancées

    Limiter les itérations (tests)

    jobs:
  rapport_region:
    foreach_query: "SELECT code_region FROM ref_regions"
    foreach_limit: 3
    sql: sql/rapport.sql

    Exécution parallèle

    jobs:
  rapport_region:
    foreach_query: "SELECT code_region FROM ref_regions"
    foreach_parallel: true
    foreach_workers: 8
    sql: sql/rapport.sql

    Comportement en cas d'erreur

    jobs:
  rapport_region:
    foreach_query: "SELECT code_region FROM ref_regions"
    foreach_on_error: skip  # abort (défaut) | skip | continue
    sql: sql/rapport.sql
    Valeur Comportement
    abort Arrête tout à la première erreur (défaut)
    skip Ignore l'itération en erreur, continue les suivantes
    continue Comme skip mais marque le job en WARNING

    Hooks par itération

    jobs:
  rapport_region:
    foreach_query: "SELECT code_region FROM ref_regions"
    foreach_pre_hook:
      file: sql/hooks/avant_chaque.sql
    foreach_post_hook:
      file: sql/hooks/apres_chaque.sql
      soft_fail: true
    sql: sql/rapport.sql

    Exemple complet — rapport mensuel par agence

    jobs:
  rapport_agence:
    foreach_query: >
      SELECT code_agence, libelle_agence
      FROM ref_agences
      WHERE actif = TRUE
    foreach_parallel: true
    foreach_workers: 4
    foreach_on_error: skip
    sql: sql/rapport_agence.sql
    target: "{{ params.schema }}.rapport_{{ code_agence }}"
    write_mode: replace
    after: [charger_clients]

    -- sql/rapport_agence.sql
SELECT
    '{{ code_agence }}'                               AS agence,
    '{{ libelle_agence }}'                            AS nom_agence,
    EXTRACT(MONTH FROM date_commande)                 AS mois,
    COUNT(*)                                          AS nb_commandes,
    ROUND(SUM(montant), 2)                            AS ca_total,
    {{ current_timestamp() }}                         AS computed_at
FROM commandes
WHERE code_agence = '{{ code_agence }}'
  AND EXTRACT(YEAR FROM date_commande) = {{ params.annee }}
GROUP BY mois
ORDER BY mois
